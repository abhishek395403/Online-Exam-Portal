# 📝 Online Exam Portal

A web-based online examination system that allows administrators to create and manage exams, and students to take them remotely.

##  Features

### For Administrators:
- Create, edit, and delete exams
- Add questions (MCQ, True/False, Short Answer)
- Set time limits for exams
- Manage student accounts
- View and analyze results

### For Students:
- Browse available exams
- Take exams within a timed session
- View results and scores
- Track exam history
